## 🚀 Proyecto Destacado: Sistema de Gestión de Expedientes (SGE)
Desarrollo de una solución integral para la administración digital de expedientes, centralizando la gestión y asegurando la trazabilidad.
* **Backend:** C#10+, ASP.NET Core Web API.
* **Arquitectura:** Clean Architecture con dependencias orientadas hacia el dominio, asegurando alta mantenibilidad y testabilidad.
* **Persistencia y Datos:** Entity Framework (EF Core), SQLite, Patrón Repositorio y Unit of Work.
* **Diseño de Dominio:** Implementación de Entidades y Value Objects inmutables (record classes) para reglas de negocio sin estados inválidos.
* **Seguridad:** Autenticación stateless con JWT y contraseñas hasheadas (SHA-256).
